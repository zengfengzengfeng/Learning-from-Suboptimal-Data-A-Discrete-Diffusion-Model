# Learning from Suboptimal Data: A Discrete Diffusion Model with Policy Improvement for Active Distribution Network Reconfiguration

This repository accompanies our forthcoming manuscript, “Learning from Suboptimal Data: A Discrete Diffusion Model with Policy Improvement for Active Distribution Network Reconfiguration.”

It currently contains datasets for the 33-bus and 192-bus distribution systems used in our study. The source code will be made publicly available in this repository after the paper is published.
